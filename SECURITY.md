# Security policy · מדיניות אבטחה

## About this project
Tik Tov (תיק טוב) is a static, client-side educational game. It has no server, no database,
no user accounts, and it does not collect or send any personal data. Progress is stored only
in the player's own browser (localStorage). A Content Security Policy blocks scripts and
connections from other sites.

## Reporting a vulnerability
If you find a security or privacy problem, please report it privately through
**GitHub → Security → "Report a vulnerability"** (private vulnerability reporting),
not as a public issue. Please include steps to reproduce.

We aim to reply within 7 days and to fix confirmed issues as soon as possible.

## דיווח על בעיית אבטחה
מצאתם בעיית אבטחה או פרטיות? דווחו בפרטיות דרך לשונית Security ב-GitHub, בכפתור
"Report a vulnerability", ולא בדיון פומבי. נשתדל לענות תוך 7 ימים.

## Supported versions
Only the latest version published at https://nirgo9116.github.io/tik-tov-israel-3d/ is supported.
